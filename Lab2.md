Контрольні запитання:

1. Динамічна типізація — використовується у випадку коли тип змінної визначається автоматично під час виконання програми. При цьому одна змінна може в різний момент містити значення різних типів.
2. PHP-блок у HTML-документі починається спеціальним відкриваючим тегом і завершується закриваючим тегом. У цьому блоці записується код, який обробляється сервером.
3. Обидва записи використовуються для виведення значення змінної. Другий варіант є скороченим записом першого.
4. Основні скалярні типи PHP — цілі числа, дробові числа, рядки та логічні значення. Вони використовуються для зберігання чисел, тексту та значень «істина/хиба».
5. PHP-код у такому .html файлі не виконається. Браузер не обробляє PHP, оскільки для цього потрібен сервер із підтримкою PHP.
