Контрольні запитання:

1. Оператори порівняння використовуються для порівняння двох значень. Основні: ==, ===, !=, !==, >, <, >=, <=.
2. == порівнює значення з можливим автоматичним приведенням типів, а === порівнює і значення, і їхні типи. Наприклад, число 5 і рядок "5" при == вважаються рівними, а при === — ні.
3. Альтернативний синтаксис зручний для використання PHP-керуючих конструкцій безпосередньо всередині HTML. Він робить код із великими HTML-блоками більш читабельним.
4. Тернарний оператор — це скорочений спосіб запису простої умови, який має вигляд: умова, знак питання, значення при істині, двокрапка та значення при хибності. Його недоцільно використовувати для складних умов, де код стає важким для читання.
4. До false при перетворенні типів приводяться false, 0, 0.0, порожній рядок, рядок "0", порожній масив та null. Також значення, яке не існує, розглядається як false в умовах.
