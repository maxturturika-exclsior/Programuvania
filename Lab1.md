Контрольні запитання:

1. Призначенням вебсерверу є приймати запити від браузера та повертати йому вебсторінки, тощо. Отримуючи певний http він здійснює автентифікацію, перевіряє права доступу й вмикає інтерпретатор. В подальшому формує http відповідь, яка містить статус-код результату операції. У свою чергу браузер після отримання даних здійснює візуальне оформлення для користувача.

2. Файл повинен володіти розширенням "php" задля вдалої обробки сервером. 

3. PHP-код виконується сервером, тому подвійний клік на .php не запускає його адже браузер не вміє сам виконувати PHP. Для цього використовують локальний вебсервер.  Файл розміщують у папці htdocs, а потім відкривають через localhost; Apache передає PHP-код інтерпретатору, а браузер отримує вже готовий результат.

4. echo - використовується для виведення на екран певної інформації (аналог print)

5. phpinfo() — виводить детальну інформацію про налаштування PHP та серверне середовище: версію PHP, встановлені модулі, конфігурацію та параметри. Використовується для перевірки й діагностики налаштувань PHP.
