$taskTitle = "Learn PHP basics - operators, variables, functions and string";

function formatTitle($text, $maxLenght = 20) {
    if ((strlen($text)) >= $maxLenght)
        return substr($text, 0, $maxLenght) . "...";
    else
        return $text;
}

function getCurrentGreeting($Time){
    if ((date($Time)) >= "06:00" && (date($Time)) <= "11:59")
        echo "Доброго ранку";
    elseif ((date($Time)) >= "12:00" && (date($Time)) <= "17:59")
        echo "Добрий день";
     elseif ((date($Time)) >= "18:00" && (date($Time)) <= "23:59")
        echo "Добрий вечір";
}

Контрольні запитання:

1. DRY (Don’t Repeat Yourself) — принцип програмування, який полягає у винесенні коду у функцію змінну чи іншу конструкцію для повторного використання, замість того, аби дублювати його зайвий раз.У моєму коді принцип DRY реалізований за допомогою функцій formatTitle() та getCurrentGreeting(). Логіка написана один раз у функції, після чого її можна повторно використовувати через виклик, не дублюючи код.

2. Аргументи функції — конкретні значення, які передаються функції під час її виклику.
    Параметри за замовчуванням — параметри, для яких заздалегідь задано значення, якщо аргумент не передали.
    У моєму випадку як приклад параметрів можна навести $text, $maxLenght, $Time. Для параметра $text аргументом прив виклику є значення "Learn PHP basics - operators, variables, functions and string". А аргументом встановленим за замовчуванням є 20 для $maxLenght.

3. Якщо у функції не вказати конструкцію return, то функція не повертає жодного значення. Тому, якщо спробувати присвоїти результат її виклику змінній, наприклад $x = myFunc(), змінна $x отримає спеціальне значення NULL.    
4. Область видимості (scope) — частина програми, де певна змінна доступна для використання. Наприклад, змінна всередині функції зазвичай доступна лише в цій функції.
Якщо у функції звернутись до $taskTitle, яка не містить приставки global то функція не матиме досупу до цієї змінної, й не зможе проводити над нею вказані маніпуляції. 
5. substr() — функція PHP для отримання частини рядка. Основні аргументи: рядок, початкова позиція та необов’язкова довжина.
